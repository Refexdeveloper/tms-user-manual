## Typography

- Primary: **Inter**
- Display: **Plus Jakarta Sans**
- Icons: **Remix Icon** (`ri-*`)
- Use `tabular-nums` for amounts / IDs

## Rules

1. White cards on soft blue/grey wash — no independent screen themes.
2. Selected states = primary border + light ring (`#1E88E5`).
3. Reuse Shell / cards / badges / buttons before adding new patterns.
4. Status colors stay mapped to KPI conventions (Active / Completed / Pending / Delayed).
